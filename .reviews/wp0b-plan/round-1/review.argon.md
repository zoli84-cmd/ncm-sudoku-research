Elolvasom a review briefet (`brief.argon.md`), hogy pontosan követhessem a bírálati szempontokat és utasításokat.

### Verdict
The WP0-B implementation plan is well-grounded in the upstream codebase and sound enough to proceed. The single most important change is extending `continue_generation` (`forward_with_intervention`) with an optional `z_hat_override` tensor hook at the handoff level so that E4 generator-mediated continuous patches on $Z_{\leq\ell}$ (`research_plan_v3.4.md` §9.2) will not require rewriting the continuation loop later.

### Findings

```
ARGON-1 | major | docs/superpowers/plans/2026-11-09-wp0b-model-instrumentation.md (Task 4: continue_generation)
Claim: `continue_generation(m, prefix_tokens, given_codes, n_given_levels)` only accepts discrete `given_codes` and provides no way to inject a continuously patched cumulative state Z_{<=l} (`z_hat`, shape `(B, 89, 256)`) before it is area-downsampled into the next generator level's input `x`. Because `vq.get_next_autoregressive_input` updates `z_hat` and calls `F.interpolate` inside a plain method rather than an `nn.Module`, PyTorch forward hooks cannot intercept `Z_{<=l}` for E4 generator-mediated patching (`research_plan_v3.4.md` §9.2).
Evidence: In `third_party/ncm/models/quant.py:446-454`, `get_next_autoregressive_input(level_idx, z_hat, z_q_level)` executes `z_hat.add_(upsampled)` and immediately returns `F.interpolate(z_hat.transpose(-1, -2), size=(self.levels[level_idx + 1],), mode="area").transpose(-1, -2)`. By contrast, generator hidden activations `H_l` pass through `self.transformer.blocks`, `self.transformer.ln_f`, and `self.lm_heads[hidx]` in `third_party/ncm/models/next_concept.py:394-398` and can already be read or patched via standard PyTorch forward hooks.
Recommendation: Add an optional keyword argument `z_hat_override: torch.Tensor | None = None` (shape `(B, 89, 256)`, valid for `1 <= n_given_levels <= 11`) to `continue_generation` (and allow `given_codes: torch.LongTensor | None = None` when `n_given_levels == 0`). At `level_idx == n_given_levels - 1`, when `z_hat_override is not None`, set `z_hat = z_hat_override.clone()` and compute `x = F.interpolate(z_hat.transpose(-1, -2), size=(m.levels[n_given_levels],), mode="area").transpose(-1, -2)` so both `x` at the handoff level and `z_hat` for all subsequent levels use the patched state. Add an identity test verifying that `z_hat_override=cumulative_states(m, clean_codes)[level - 1]` reproduces branch B/A bit-for-bit, and expose `decode_state_logits(m, z) -> torch.Tensor` (`m.vqvae.decoder(z)`, shape `(n, 89, 12)`) in `states.py` for E4's digit-logit margin endpoint (`research_plan_v3.4.md` §9.2).
Confidence: high
```
