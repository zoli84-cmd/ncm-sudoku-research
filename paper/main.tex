\title{Hierarchical sensitivity and logical readability in a coarse-to-fine Sudoku generator: a preregistered study}

\begin{abstract}
Next-Concept Modeling (NCM) generates a Sudoku solution as a hierarchy of discrete codes, from one coarse code to many fine ones. We ask, in a preregistered confirmatory study on one released checkpoint and \R{n.test} fresh puzzles, where the logic of the puzzle shows up in this hierarchy. Decoding teacher codes reproduced every solution, so all failures came from generation. Replacing the single level-1 code lowered the solve share by \R{h2.est.abs} percentage points more than replacing one level-11 code (\R{level.family}\% family interval [\R{h2.fam.lo}, \R{h2.fam.hi}]), under a frequency-based replacement policy. Regenerating the later levels after a level-1 replacement attenuated the damage by \R{h3.est} points ([\R{h3.fam.lo}, \R{h3.fam.hi}]), consistent with the model's training against corrupted levels; it does not show logical error correction. The candidate mask of the puzzle was linearly readable from the level-6 state above a permuted control, but only by \R{h1.est} in Brier loss, inside the registered equivalence range of $\pm$\R{plan.h1margin}, while the same label is almost exactly readable from the raw puzzle. At the last level the readout matched the teacher state that encodes the solution and was not equivariant under Sudoku symmetries. The results locate a large sensitivity at the coarsest level, while the intermediate level-6 state exposes the puzzle's candidate structure to a linear readout only below the practical threshold; we report each result with the claims that do not follow from it.
\end{abstract}
