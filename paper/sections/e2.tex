\section{E2: level sensitivity and compensation}
\label{sec:e2}

\subsection{Design}
\label{sec:e2-design}

E2 asks how strongly the solve outcome depends on a single code at different levels, and whether generating the later levels after an intervention makes up for part of the damage. For each puzzle we record the clean run and then compare four branches that share every code before the intervention level. Branch A replays the clean codes. Branch B restarts generation after the intervention level without changing anything (a sham restart; in a deterministic run B must equal A). Branch C replaces codes at the intervention level and replays the original later levels, so it measures the direct effect of the replacement on decoding. Branch D makes the same replacement and generates the later levels anew, so it measures the total effect, including any adaptation of the later levels.

The primary edit is a single code replacement. A replacement value is drawn from the level's generated code frequencies estimated on the calibration set, excluding the original value (frequency policy); a uniform choice among the other values is the secondary policy. Level~1 has a single code, so instead of sampling we run all alternative values and weight them by their calibration frequencies, which gives the exact expectation over the policy. At the other levels a dose of $k$ codes draws $k$ distinct positions and a replacement value for each, with three intervention seeds per puzzle and dose. For every replacement we also record its initial damage: the mean over all cells of the total variation distance between the decoder's output distributions in branches C and A, a continuous measure of how much the replacement changes the decoded output before any regeneration. The two primary contrasts are
\[
\theta_2 = \mathbb{E}\bigl[(Y_{D,1}-Y_A)-(Y_{D,11}-Y_A)\bigr],
\]
and, at level~1,
\[
\theta_{\mathrm{comp}} = \mathbb{E}\bigl[(Y_D-Y_C)-(Y_B-Y_A)\bigr],
\]
where $Y$ is the binary solve outcome of a branch. A negative $\theta_2$ (H2) means that one replaced code costs more at level~1 than at level~11; a positive $\theta_{\mathrm{comp}}$ (H3) means that regenerating the later levels leaves the puzzle solved more often than replaying them, corrected for the sham restart. One code at each level is an equal number of discrete edits, not an equal semantic change. Level~1 is also architecturally distinct: its single code passes through a learned upsampler, so replacing it changes the whole level-1 state.

The sham restart reproduced the clean run exactly: for every puzzle and every intervention level studied, branch B produced the same codes and the same outcome as branch A, and the level-1 rows that replace a code by itself (weight zero) reproduced A and B as well. The intervention path therefore adds no difference of its own.

\subsection{Level sensitivity (H2)}
\label{sec:e2-h2}

Under the frequency policy, the single level-1 replacement lowered the solve share from \R{e2.l1.frequency.A}\% in branch A to \R{e2.l1.frequency.D}\% in branch D, while a single replacement at level~11 left it at \R{e2.cfg.L11.frequency.d1.D}\%. The primary contrast was $\theta_2 = \R{h2.est}$ percentage points, with a family interval of [\R{h2.fam.lo}, \R{h2.fam.hi}] (\R{level.family}\%; Figure~\ref{fig:contrasts-forest}); \R{h2.nnz} of \R{h2.n} puzzles had a nonzero difference. The whole interval lies beyond the pre-specified practical threshold of \R{plan.h2practical} points. The uniform policy gave a larger contrast (\R{uniform.theta2.est} points, \R{level.ci95}\% interval [\R{uniform.theta2.ci.lo}, \R{uniform.theta2.ci.hi}]), and so did the puzzles whose clean run was solved (\R{cb.theta2.est} points, \R{cb.theta2.n} puzzles).

Following the registered interpretation, this supports a greater sensitivity of the solve outcome to one code at level~1 than at level~11 under the given replacement policy. A descriptive comparison speaks against reading this contrast as a mere difference in edit size: replacing every level-11 code under the frequency policy produced a median initial damage of \R{e2.cfg.L11.frequency.d67.tv.med} (\R{e2.cfg.L11.frequency.d67.tvempty.med} over originally empty cells), close to that of the single level-1 replacement (\R{e2.l1.frequency.tv.med}; \R{e2.l1.frequency.tvempty.med}), yet branch D still solved \R{e2.cfg.L11.frequency.d67.D}\% of the puzzles against \R{e2.l1.frequency.D}\% after the level-1 replacement (Table~\ref{tab:e2-diagnostics}; the level-1 medians summarize per-puzzle expectations and the level-11 medians puzzle--seed runs). It does not show that the coarse code is an explicit plan of a solving algorithm. Because level~1 is a single code behind a learned upsampler, it does not imply a graded sensitivity along the early levels or a sensitivity that is independent of that architecture.

\subsection{Compensation (H3)}
\label{sec:e2-h3}

At level~1 the direct effect of the replacement (branch C) was a solve share of \R{e2.l1.frequency.C}\%; generating the later levels anew (branch D) gave \R{e2.l1.frequency.D}\%. With the sham correction, $\theta_{\mathrm{comp}} = \R{h3.est}$ percentage points, with a family interval of [\R{h3.fam.lo}, \R{h3.fam.hi}]; \R{h3.nnz} of \R{h3.n} puzzles had a nonzero value. Because the interval excludes zero, regenerating the later levels attenuated the effect of the replacement. The net effect combines puzzles in both directions: of the \R{h3.nnz} puzzles with a nonzero value, regeneration left the puzzle solved more often than replaying in \R{h3.disc.pos} and less often in \R{h3.disc.neg}. The estimate lies below the practical threshold of \R{plan.h3practical} points used for sample-size planning, and the interval contains values on both sides of it. The attenuation is therefore small, and its practical relevance is not established. The uniform policy (\R{uniform.thetacomp.est} points) and the correct-baseline subset (\R{cb.thetacomp.est} points) gave estimates of the same sign and size.

NCM training, as described for the method, corrupts earlier levels \citep{kumbong2026ncm}; if this checkpoint was trained that way, a positive compensation is consistent with the robustness that the training objective rewards. It does not show that the model detects or repairs logical errors, and the improvement in D need not be logical error correction: the regenerated codes may fit the changed prefix better than the replayed ones.

\subsection{Levels 2 and 11, doses and propagation}
\label{sec:e2-secondary}

A single replacement at level~2 and at level~11 gave practically the same solve outcome: the difference was \R{theta2p.est} points, and because only \R{theta2p.nnz} puzzles had a nonzero difference, the registered rare-event bound replaced the bootstrap: at the one-sided \R{level.ci95}\% level the difference lies within [\R{theta2p.tost.lo}, \R{theta2p.tost.hi}], inside the equivalence range of $\pm$\R{plan.theta2pmargin} points. This supports the absence of a practically relevant difference between levels 2 and 11 under the frequency policy; it does not show that level~2 carries no information or has no causal role.

The descriptive dose curves, the curves on the initial-damage axis and the spread of a replacement to the later levels are reported in Appendix~\ref{sec:appendix-e2} (Figures~\ref{fig:dose-curves} to~\ref{fig:damage-curves}). At level~6, replaying the later levels left the solve share at the baseline for every dose, whereas regenerating them lowered it; at level~11 both branches declined with the dose. The registered comparison of dose curves over a damage range frozen on the calibration set could not be computed, because the TEST damage values did not cover that range; this is a pre-specified outcome, not a failure of the run.
