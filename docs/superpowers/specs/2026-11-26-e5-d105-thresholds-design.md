# E5 D105 draft: confirmatory thresholds, error rates and TEST size

Status: final after review rounds R1 (sol; neon returned no review), R2 (sol, neon) and Final (astra) (`.reviews/e5-d105-thresholds/decisions.md`); recorded as D105 in `DECISIONS.md`. Fixes the numbers and decision procedures the E5 protocol will preregister; written after the pilots (D100–D104) and before any TEST pair exists. Non-confirmatory planning decision. Where it differs from D101 (bootstrap decision intervals, switch to exact bounds at the ceiling, family split), D105 supersedes D101.

## Context

E5 asks whether the weak linear readout of the level-6 candidate mask in the NCM Sudoku generator's cumulative state Z<=6 is a property of that state or of the generator. Design so far (all in `DECISIONS.md`):

- Counterfactual pairs (one solution, two 30-clue masks) from the project's frozen generator (D97, D99); TEST pairs will come from a fresh seed namespace (10) with the canonical-form orbit exclusion of D99.
- D101: primary readout = seed-averaged shared own-position linear head (D55) for both Z<=6 and the prefix layer k* (P2 in the pilot, fixed on PROBE-VAL); W = mean over pairs of the per-pair within-pair AUC (W-AUC, ties scored 0.5); primary contrast Delta = W(P_k*) − W(Z<=6) on the same pairs.
- D102–D104: activation-exchange causal test at layer 2 of the prefix, level-7 pass with the recipient's levels 1–6 fixed; primary outcome = directed TV movement of the level-7 code distributions towards the both-empty full-swap reference; controls: norm-matched random subspaces, a high-variance control (cosine with the full difference 0.471 vs. Q 0.541), a shuffled-digit control.

Pilot per-pair statistics (PROBE-VAL, 250 pairs; recomputed by the R1 reviewer): W(Z<=6) 0.5036, SD 0.0445 (96 values exactly 0.5, including all 88 code-identical pairs); P2 per-pair W-AUC 1.0 in all 250 pairs; Delta 0.4964, SD 0.0445, minimum 0.304; causal Q directed 0.052, SD 0.061; Q minus high-variance 0.030, SD 0.041; Q minus random mean 0.049; Q minus shuffled 0.131; 71 of 500 recipients have TV(clean, full) below 0.01. Per-pair causal arrays exported for review: `experiments/e5/causal/primary_per_pair.json`.

## Decision D105

1. Claims and error control. Two confirmatory claims, each at alpha = 0.025 (family-wise 0.05 over the two claims): (A) the state reading (with the frozen own-position linear probe, the candidate mask is readable within pairs from the prefix layer k*, and the probe's within-pair readout of Z<=6 is practically equivalent to non-discrimination), and (B) the causal reading (the level-7 code distribution moves towards the full-swap reference under the candidate-subspace patch beyond the named controls). Each claim is a conjunction of conditions; by the intersection-union principle every condition is tested at the full 0.025 and the claim holds only if all its conditions hold. Conditions are not reported as separate confirmatory results.
2. Decision bounds. Every decision is a one-sided level-0.025 test of a bounded per-pair mean by betting (Waudby-Smith and Ramdas 2024, "Estimating means of bounded random variables by betting", JRSSB), in the unhedged one-sided form: for a lower-bound condition with null boundary m_0 (A1 lower, A2, B1–B4), the capital process K_n(m_0) = prod_i (1 + lambda_i (X_i − m_0)) with full capital on the positive branch; for the A1 upper condition, the same process on 1 − X; the condition holds when the capital at the null boundary reaches 40 = 1/0.025 (strict comparison after the last pair). Quantities on [−1, 1] (Delta, the causal contrasts) are rescaled by (x + 1)/2 with the boundary rescaled accordingly. Bets: fixed-n predictable plug-in, lambda_{i+1} = min( sqrt(2 log(40) / (N v_i)), c / m_0 ) with mu_i = (0.5 + sum_{j<=i} X_j)/(i + 1) and v_i = (0.25 + sum_{j<=i} (X_j − mu_j)^2)/(i + 1) (so mu_0 = 1/2, v_0 = 1/4), c = 0.75; N in the bet is the planned number of pairs, and the number of eligible pairs entering each product is a separate, reported variable. The decision is terminal: log K after the last pair > log 40 (not the running maximum). Transformed null boundaries on [0, 1]: A1 lower 0.47 on X and A1 upper 0.47 on 1 − X; A2 0.625; B1 0.505; B2–B4 0.5 (B1 is a difference of two TV distances, in [−1, 1]). One function implements this for the simulation and the TEST run. Pairs are processed in raw generation index order (see below). There is no confidence-set inversion and no data-dependent branch; this replaces the D101 pair-level bootstrap and its switch to exact bounds at the ceiling. Pair-level bootstrap intervals are reported for estimation only. The implementation is fixed in code before TEST and checked on synthetic data: constant samples, many ties at 0.5, all values 1.0 (a lower bound must not exceed 0.025^(1/N)), extreme two-point distributions ({0, 1}, {−1, 1}) at the boundary, and coverage at the nominal level. The preregistration promises the error level only for this procedure. Inference is conditional on the frozen probe heads (fitted on PROBE-TRAIN), and for claim B also on the frozen high-variance basis, the fixed digit derangement and the 20 named random bases (seeds 1000–1019, as in the pilot), each identified by SHA-256. Pairs are i.i.d. only if the TEST sample is not altered by its own content: candidates are screened against the earlier, fixed datasets (gate, CAL, PROBE, WP2 TEST, released set, the E5 PROBE pairs), and the raw generation index runs from 0 until the N-th externally accepted pair; the TEST set is these accepted pairs in raw index order. If two of them share a solution orbit, neither claim is made, and no candidate is replaced or redrawn; for TEST this overrides the internal replacement rule of D99. The error guarantee covers this whole procedure, not the collision-free case conditionally.
3. Claim A conditions. (A1) Equivalence of Z<=6: both one-sided tests reject, i.e. W(Z<=6) > 0.5 − epsilon and W(Z<=6) < 0.5 + epsilon, with epsilon = 0.03. Centre 0.5: the tie-scored W-AUC of a ranking that does not discriminate candidate from non-candidate members, not an empirical control mean (D101: the E3 controls are diagnostics). Justification of 0.03 independent of the expected result: with ties scored 0.5, W − 0.5 = (p_win − p_loss)/2, so epsilon = 0.03 allows a pair-weighted excess of 6 net correct orderings per 100 discordant comparisons; this is treated as negligible next to readouts that order nearly all of them (about 100 net). Forced ties from locally identical Z<=6 states count as ties and dilute the margin (in the pilot about 60% of discordant bits were forced ties, so 0.03 over all pairs corresponds to about 15 net per 100 on the remaining bits, an illustration weighted with the pilot tie share, not a margin for that stratum); the separate report of D101(4) shows both. Claim A is stated as practical equivalence of the frozen own-position linear probe on all eligible pairs, not as absence of candidate information in Z<=6. (A2) Minimum difference: the one-sided test of Delta > 0.25 rejects. Justification: a large effect on the W-AUC scale; with W(Z<=6) inside the band it requires a tie-credited prefix W-AUC of about 0.72–0.78; it is not derived from the pilot value.
4. Claim B conditions (D102(7) kept, with the D104 control). The one-sided test of mean > threshold rejects for each of: (B1) the Q directed effect, threshold 0.01, i.e. an average movement of one percentage point of total variation towards the reference; recipients whose reference distance is below 0.01 stay in the mean, and the heterogeneity across recipients is reported descriptively; (B2) Q minus the mean of the norm-matched random subspaces, threshold 0; (B3) Q minus the high-variance control, threshold 0; (B4) Q minus the shuffled-digit control, threshold 0. The claim is limited to movement of the level-7 code distribution towards the reference relative to these controls under this intervention; no mechanistic digit-specific claim is made, because the controls are matched in norm but not in alignment with the full difference.
5. TEST size and scope. N = max(N_power, 250) pairs from seed namespace 10. N_power is the smallest N on a grid of 50 (from 250 to a cap of 1,000) at which the simulation of item 6 gives a power of at least 0.9 for each claim under the chosen planning model (6b), not under the pilot model; each grid point uses 2,000 replications (Monte Carlo SE about 0.0067 near a power of 0.9, larger elsewhere), with two fixed simulation seeds, one for the grid search and one for the separate re-check of the chosen N. If no grid point up to 1,000 reaches 0.9, or the re-check falls below 0.9, there is no lock and no TEST generation. 250 (the PROBE-VAL size) is a budget floor for the descriptive secondary analyses (code-different stratum, inference-wave depth, level-7 query readout); no precision target is committed for secondary strata, which are reported with intervals. Eligibility is decided from the labels before any scoring (a pair without a discordant bit is excluded from claim A and counted; claim B uses all pairs with at least one both-empty cell); the A and B denominators are reported separately, Ineligibility (from labels) is distinct from an invalid run: a non-finite model output stops the run, and a hash mismatch, a wrong hook-application count, a failed query-isolation, identity or norm check makes claim B not confirmable (the failing pair is not simply dropped); the per-condition step alignment is logged as a diagnostic, not tested. The full-generation causal variant and the rescue/harm analysis are not part of TEST (exploratory, later, if at all). N is fixed before TEST generation and never changed after TEST outcomes.
6. Simulation (before TEST generation; its code and seed fixed with the protocol). The generating model resamples whole per-pair outcome vectors from the PROBE-VAL pilot (W(P), W(Z), and the per-condition directed effects of Q, the random-subspace mean, the high-variance and the shuffled-digit controls, both orders averaged), so forced ties, ranges and identities are kept; Delta and the causal contrasts are always recomputed from the resampled components. Scenario transformations, each checked for its generating means: W(Z) moved by full-row exponential reweighting of the resampling weights that keeps the total weight of the rows with W(Z) exactly 0.5; the prefix weakened by W(P) = 0.5 + kappa (W_P2 − 0.5); causal effects scaled jointly (every condition's directed effect multiplied by the same factor), and a single causal contrast moved by raising the control's directed effect towards Q's. (a) Pilot model, for reference. (b) Chosen planning model, used for N: all causal directed effects scaled by 0.5, kappa = 0.7 (W(P) about 0.85), W(Z) reweighted to 0.515; at the chosen N also a same-mean heterogeneous sensitivity case (each pair keeps all its causal effects with probability 1/2, otherwise all zero), reported but not used for N. (c) Null boundaries with exactly one condition false and the others holding: W(Z) reweighted to 0.47 and to 0.53; kappa chosen so that the mean of Delta is 0.25; all causal effects scaled jointly so that the Q effect is 0.01 (B1; Q − high-variance stays positive); for B2, B3, B4 the control C is mixed towards the both-empty full-swap reference F, C' = (1 − t) C + t F with t = (E[Q] − E[C]) / (E[F] − E[C]), so the contrast has mean 0 with both signs present and the reference bound kept, all other columns unchanged; the false-positive rate is reported only for the condition at its null and for the claim containing it, with its Monte Carlo SE. These are checks within a planning model whose heads were selected on PROBE-VAL, not a calibration of the fresh TEST.
7. Procedure. The TEST run uses a separate frozen TEST runner, not the pilot scripts: frozen head, basis and control identifiers (SHA-256), pair ids, the screening log (candidates rejected against earlier datasets; internal collisions handled as in item 2), verified-identical inputs scored as ties, eligibility from labels before scoring, a stop on any non-finite model output, no silent reduction of the denominator; the bound implementation and tie handling are tested on synthetic data before TEST generation.
