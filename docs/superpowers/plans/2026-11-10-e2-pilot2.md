# E2 Pilot 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement and run the second, non-confirmatory E2 pilot on the 300 CAL puzzles as specified in plan v3.6. Then compute the E2 part of the TEST sample size.

**Architecture:**
- New modules:
  - `damage.py`: damage and diagnostic measures.
  - `e2p2.py`: the pilot-2 runner and its estimators, intervals and AUC.
  - `power.py`: the sample-size simulation.
- Small additions to `perturb.py`: extended dose grid, collision-free seeds, level-1 enumeration weights.
- `e2.py` (pilot 1) stays unchanged so that pilot 1 remains reproducible.
- Statistics work on puzzle-level arrays with numpy, so the 10,000-resample bootstrap and the simulation are fast.

**Tech Stack:** Python 3.12, torch 2.15 (CPU, FP32, deterministic), numpy, pytest. No new dependencies.

**Spec:** `research_plan_v3.6.md` §7.2, §7.3, §11.1, §11.2, §11.4, §12.1; `DECISIONS.md` D43–D52 (D51 and D52 supersede parts of D47–D49).

## Global Constraints

- All files are written in English. FP32, eager mode, `torch.use_deterministic_algorithms(True)`, CPU on native Windows (D30).
- Never modify `third_party/ncm`. Load checkpoints only through `ncm_sudoku.model.load_model`.
- CAL means `generate_subset("cal", 300)` (seed namespace 2). TEST is never generated or touched.
- Levels: 1, 2, 6 and 11. Code lengths come from `m.levels`, and the codebook size is 16.
- **Dose grid (v3.6):**
  - distinct values of {1, ⌈.05n⌉, ⌈.15n⌉, ⌈.30n⌉, ⌈.60n⌉, n};
  - level 2 → [1, 2]; level 6 → [1, 2, 4, 8, 13]; level 11 → [1, 4, 11, 21, 41, 67];
  - level 1 → single replacement, enumerated (no dose grid).
- **Level-1 weights:** w_{i,v} = f̂_v / Σ_{k≠a_i} f̂_k for v ≠ a_i. Zero frequency means zero weight. A puzzle is ineligible only if the denominator is 0. Uniform policy: 1/15 for each v ≠ a_i.
- f̂ = level-1 code frequencies of the CAL generated codes (branch A), frozen and saved in the summary.
- Levels 2, 6 and 11 use 3 intervention seeds (0, 1, 2) and both policies, `frequency` and `uniform`.
- **TV damage:** d = mean over the 81 cell positions (`CELL_TOKEN_INDICES`) of ½Σ_t|p^C_t − p^A_t|. Here p = softmax (T = 1) of the decoder logits over all 12 tokens, from the final cumulative state. An empty-cell variant averages over the cells with puzzle value 0.
- **Primary contrasts (family, Bonferroni level 1 − 0.05/3 ≈ 0.98333):**
  - θ₂ = mean_i[Σ_v w_iv(Y_D1,iv − Y_A,i)] − mean_i[mean_s(Y_D11,is − Y_A,i)], with level 11 under the frequency policy at dose 1;
  - θ_comp = mean_i[Σ_v w_iv(Y_D1,iv − Y_C1,iv) − (Y_B1,i − Y_A,i)].
- **Secondary:**
  - θ₂′ = levels 2 vs. 11 (frequency, dose 1), with a 90% interval for TOST at ±3 pp;
  - uniform-policy versions of all three.
- **Intervals:**
  - percentile cluster bootstrap over puzzles, 10,000 resamples, seed 0;
  - **rare-event rule:** if fewer than 20 puzzles have a nonzero puzzle-level value, use the bound |δ| ≤ q instead. q_upper is the one-sided Clopper–Pearson limit at the contrast's level (0.98333 for primary contrasts, 0.95 otherwise; for TOST, 0.95 per side).
- **AUC:**
  - pairs (6, 11) and (2, 11), frequency policy;
  - nodes: one per dose, x = mean TV and y = mean (Y_D − Y_A), each averaged first over seeds within a puzzle and then over puzzles;
  - nodes with equal x are merged by averaging their y;
  - a curve needs at least two distinct x values;
  - range = [max of the two curves' min x, min of their max x], with positive width required;
  - exact piecewise-linear integral, divided by the range width;
  - otherwise the AUC is `None`, with a reason.
- **Sample size (E2 part):**
  - candidate n = 100, 200, …, 3000;
  - **H2:** two scenarios (thinning; sign-mixing); target 90% power, defined as the 98.33% interval excluding 0;
  - **H3:** the observed puzzle-level values; target half-width ≤ 0.03 in ≥ 80% of simulated runs;
  - **equivalence:** sign-flip null; target ≥ 80% probability that the 90% interval lies inside ±0.03; the error rate at the ±0.03 boundary (sign-mixing to ±0.03) is reported;
  - every simulated sample runs the real interval rule;
  - result: the smallest n meeting each target, and their maximum, rounded up to 100.
- Simulation planning parameters (ledgered, not from the spec): 500 simulated samples per n, 1,000 bootstrap resamples inside the simulation, simulation seed 0.
- The pilot is **non-confirmatory**, and every written artifact says so.

## Review Focus

1. A puzzle whose level-1 code is the only code with CAL mass. Expect weights of zero for all values, the puzzle marked ineligible for the frequency policy, and no division by zero. Pinned by `test_level1_weights_ineligible_when_only_original_has_mass` (Task 1).
2. A full-level dose (dose = n) under the frequency policy, where a position has no alternative mass. Expect the row to be ineligible and left unchanged, never a crash. Pinned by `test_full_dose_frequency_ineligible_row` (Task 1).
3. A branch-C output with a format error. Expect TV damage defined (finite, in [0, 1]) while cell Hamming is `None`. Pinned by `test_tv_defined_for_any_logits` (Task 2) and `test_run_pilot2_small` (Task 3).
4. A zero residual in the re-quantization diagnostic. Expect a ratio of 0.0, not NaN. Pinned by `test_requant_zero_residual` (Task 2).
5. A contrast with fewer than 20 nonzero puzzles, or all zeros. Expect method "bound", a nonzero width, and never a zero-width bootstrap interval. Pinned by `test_interval_switches_to_bound` (Task 4).

  - `summarize2(out: dict, n_boot: int = 10000) -> dict`, with these parts:
    - `non_confirmatory: True`;
    - `freqs_level1`;
    - per contrast and policy: estimate, a 95% interval and the family-level interval (θ₂ and θ_comp under the frequency policy: 0.98333; θ₂′: 0.90 for TOST plus 0.95);
    - `equivalence_tost`: true or false;
    - per-configuration tables: solve means A–D, exclusion share, format-error shares, damage quantiles (tv, tv_empty, hamming, latent, codebook_rms, requant_ratio);
    - level-1 weighted solve means;
    - `auc` for the pairs (6, 11) and (2, 11).

### Task 5: Sample-size simulation (E2 part)

**Files:**
- Create: `src/ncm_sudoku/power.py`
- Test: `tests/test_power.py`

**Interfaces:**
- Consumes: `interval` (Task 4).
- Produces:
  - `thin(x: np.ndarray, target: float, rng) -> np.ndarray`: keeps each nonzero element with probability target/|mean(x)|.
  - `sign_mix(x: np.ndarray, target: float, rng) -> np.ndarray`: keeps |x| and gives each nonzero element the sign of `target` with probability p = (1 + |target|/mean|x|)/2. Raises ValueError if mean|x| < |target|.
  - `sign_flip(x: np.ndarray, rng) -> np.ndarray`: multiplies each element by an independent ±1.
  - `required_n(sampler, criterion, ns=range(100, 3001, 100), reps=500, seed=0) -> int | None`: the smallest n whose criterion success share meets its target.
