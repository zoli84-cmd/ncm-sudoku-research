# WP5 TMLR Submission Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn `paper/` into one TMLR-format source with an anonymous submission build and a named build, a main text of at most 12 pages, and automatic anonymity and page checks.

**Architecture:** Two thin top-level files (`main.tex` named, `main_anon.tex` anonymous) set a switch and the `tmlr.sty` option, then load the shared `preamble.tex` and `body.tex`. Identifying text goes through one macro `\anon{named}{anonymous}`. `scripts/wp4_build.py` builds either variant; its anonymous check reads the text and metadata of the compiled PDF (PyMuPDF), its page check reads the page of a `\label{main-end}` from the `.aux` file. Shortening moves paragraphs and figures to the appendix without deleting results.

**Tech Stack:** LaTeX with Tectonic 0.17.0, TMLR style file (JmlrOrg/tmlr-style-file at `7bf90efe3a0debbba703c05c43f3ff7e4d4a2992`), Python 3.12 with uv, pytest, PyMuPDF (new dev dependency).

**Spec:** `docs/superpowers/specs/2026-11-18-wp5-tmlr-design.md`

## Global Constraints

- `tmlr.sty`, `tmlr.bst`, `fancyhdr.sty` are vendored unmodified into `paper/`; SHA-256 `816214ff5919aa457b6b443bee52b15d9561421417b7f8a50cc84651519f0002`, `306fd454cf40771bee01293eeb98d2c1cd5f4e11ed0cd7296b335f354fc45206`, `3d2922548e0e5f1a6c5676eda6ebb6dc20d7d305b4d8c2be5f1c833fb1084e6d`.
- Anonymous build: `\usepackage{tmlr}`; named build: `\usepackage[preprint]{tmlr}`; both `\documentclass[10pt]{article}`; no `geometry`, no `natbib[numbers]`; `\bibliographystyle{tmlr}`.
- Main text at most 12 pages in the anonymous build (page of `\label{main-end}`, placed right before `\bibliography`).
- Forbidden in the anonymous PDF text and metadata (case-insensitive, accents optional): `Kárász`/`Karasz`, `Zoltán`/`Zoltan`, `0009-0009-7094-6727`, `orcid`, `zoli84`, `ncm-sudoku-research`, `osf.io`, `hb8vq`, `m28fx`, `10.17605`, `1047668`, `prereg-v3.7`, `wp2-code`, `Bosch`, `ppke`, `sztaki`, `independent researcher`.
- No new analysis, number or result; moving text must keep every `\R{key}` and every confirmatory claim, registered "does not follow" boundary, preregistration disclosure and the AI-use section in the main text (spec, Anti-goals).
- `paper/AGENTS.md` rules hold: numbers only via `\R{key}`, US spelling, no Oxford comma, registered terms unchanged.
- Every PDF stays git-ignored; nothing in `paper/build/` is committed.

## Review Focus

1. A forbidden string reaching the anonymous PDF through a generated value (`\R{code.commit}`), a figure, a bibliography entry or PDF metadata: the anonymous check must read the compiled PDF, pinned by `test_anon_check_flags_generated_commit` (Task 3).
2. The page check reading a stale `.aux` or a label on the wrong page after floats move: pinned by `test_main_end_page_reads_hyperref_newlabel` and the build ordering in Task 3.
3. The two builds drifting in content: pinned by the PDF text comparison step in Task 7.
4. A moved paragraph or a `\R{key}` silently lost during shortening: pinned by `test_baseline_keys_still_used` (Task 5) and the sentence check in Task 6.
5. Citation commands that render badly under author-year natbib (numeric-only assumptions such as "in [7]"): checked by reading the anonymous PDF in Task 2 Step 5.
