# WP4 Phase 1 (manuscript infrastructure) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A buildable LaTeX manuscript skeleton whose every result number, table and data figure is generated from committed result files, with checks that forbid hand-typed numbers.

**Architecture:** Pure logic in three new package modules (`wp4numbers` for number macros, `wp4tables` for LaTeX tables, `wp4figures` for matplotlib figures) plus `texlint` for the manuscript checks; two thin scripts (`scripts/wp4_figures.py` writes `paper/generated/`, `scripts/wp4_build.py` runs Tectonic). The manuscript reads numbers only through one macro, `\R{key}`, which fails the build on an unknown key.

**Tech Stack:** Python 3.12 (uv), matplotlib (new dependency, Agg backend, PDF output), pytest; Tectonic for LaTeX.

**Spec:** `docs/superpowers/specs/2026-11-15-wp4-manuscript-design.md` (approved 2026-11-15). Also binding: root `AGENTS.md`, `research_plan_v3.7.md` §13, `DECISIONS.md` D83–D84.

## Global Constraints

- Every project file is in English; plan §13 hedging; never invent numbers.
- Inputs are committed files only: `experiments/wp2/test/results.json`, `experiments/g0/reproduction.json`, `experiments/lock/test_set.json`. No `runs/` input, no model, no network in the generator, no statistics beyond formatting stored values.
- `experiments/` is read-only. Do not modify `src/ncm_sudoku/wp2*.py`, existing scripts or `third_party/ncm`.
- Generated files go to `paper/generated/` and are committed; build output goes to `paper/build/` (git-ignored).
- Plan constants are imported from `ncm_sudoku.wp2eval` (`H1_MARGIN`, `THETA2P_MARGIN`, `THETA_T_MARGIN`, `EQUIV_TOLERANCE`); the two practical thresholds absent there are defined once in `wp4numbers` as `H2_PRACTICAL = 0.05` and `H3_PRACTICAL = 0.03` (plan §11.4, D44).
- Negative numbers render as `\ensuremath{-}` followed by the magnitude.
- Placeholders: author, affiliation and licence use `\placeholder{...}`; `scripts/wp4_build.py --arxiv` fails while any placeholder remains.
- Fast suite stays green: `uv run pytest -q`.

## Review Focus

1. A key renamed or missing in `results.json` (for example a `None` interval on the bound path) must raise a `KeyError`/`ValueError` naming the key, never emit an empty or "None" macro — test in Task 2.
2. Generated files out of date after an input or code change must be detected: `scripts/wp4_figures.py --check` exits non-zero when any committed generated file differs — test in Task 6.
3. Figure PDFs must be byte-identical across two runs (no timestamps), or `--check` is useless — test in Task 5.
4. A number hidden in a LaTeX construct the lint skips (inside `\textbf{}`, a table cell in a section file, a `$...$` math span, a percentage written `5\%`) must still be caught; comments (`% ...`) must not be — tests in Task 3.
5. An unknown `\R{key}` must fail both the lint (key not in `numbers.json`) and the LaTeX build (`\PackageError`), not print nothing — tests in Tasks 2 and 3.
