# scripts

DOX rules and project contracts are inherited from the project root [AGENTS.md](../AGENTS.md).

## Purpose

Command-line entry points that fetch data, generate subsets, run experiments, and write committed results under `experiments/` and raw outputs under `runs/`.

## Ownership

- Owns every script in this folder; script tests live in `tests/` (`test_*_script*.py`, `test_lock_*.py`, `test_e3_*.py`)

## Local Contracts

- Most result writers are rerun-guarded and refuse to overwrite unless `--force` (or `--resume`) is given; check the per-script contract below before forcing a rerun
- `wp1_gate.py` is single-look: `experiments/wp1/gate.json` must never be regenerated

## Verification

- From the project root: `uv run pytest -q`
